# PADO ON — 부산 바다를 켜다

부산 바다의 사계절 행사와 체험을 발견하고, 미리 예약하고, 참여 후 리워드까지 받을 수 있는 관광 웹앱 프로토타입입니다.

## 주요 기능

- 봄·여름·가을·겨울 맞춤형 부산 바다 추천
- 로그인 없이 공개 행사 탐색 및 계절·테마·지역 필터링
- 날짜·인원 선택, 가격 계산, 예약번호 발급
- 예약 관리 및 참여 완료 후 파도 포인트 지급 체험
- 데스크톱과 모바일에 대응하는 반응형 디자인

## 로컬 실행

`index.html`을 브라우저에서 열거나 정적 파일 서버로 실행하면 됩니다.

```powershell
python -m http.server 8000
```

그다음 <http://localhost:8000>으로 접속하세요.

## 안내

화면에 표시되는 행사와 일정은 서비스 콘셉트 시연을 위한 예시입니다. 예약과 리워드는 브라우저의 로컬 저장소에 저장되며 실제 결제나 서버 통신은 발생하지 않습니다.
