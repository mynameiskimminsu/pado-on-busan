# 오로나민-SEA — 사계절 부산 바다

부산 바다의 사계절 체험을 발견하고 예약하고, 참여 완료 후 SEA 포인트를 받는 관광 웹앱 프로토타입입니다.

## 주요 기능

- 봄·여름·가을·겨울별 부산 바다 체험 추천
- 누구나 볼 수 있는 10개 행사와 테마·지역 필터
- 체험비 없이 SEA 포인트만 보여주는 사전 예약 흐름
- 완료된 체험 및 500 SEA 포인트 적립 예시
- 개인 체험 사진과 글을 게시하는 바다 이야기
- 모바일·태블릿·데스크톱 반응형 화면

예약, 포인트, 사용자가 올린 사진과 글은 브라우저의 로컬 저장소에 저장됩니다. 따라서 같은 기기와 브라우저에서는 새로고침 후에도 유지되지만 다른 기기와 자동으로 공유되지는 않습니다.
